\sectionTitle{项目经历}{\faiconsixbf{users}}


\datedsubsection{\textbf{AcademicAgent：可控学术论文写作 Agent}}{2026.06 -- 至今}
\textbf{技术栈：}Python, Workflow, Agent, Harness Engineer, Langfuse, Pytest

\textbf{项目描述：}面向 LaTeX、Markdown 与 Word 学术文档构建可控写作 Agent，支持自然语言驱动的润色、改写、新增章节、格式转换与排版。

\textbf{项目亮点：}
\begin{itemize}
	\item 设计意图驱动的规划执行架构，将自然语言需求拆解为原子要求与有序 Operation，结构化维护目标、约束、引用配额及执行状态；结合缺失信息澄清、计划校验与有界重规划，将模糊需求收敛为可执行计划。
	\item 将 \textbf{Function Calling 与 JSON Schema} 作为结构化抽取协议，为不同写作意图定义独立槽位模型；区分模型调用失败与字段缺失、歧义、非法等状态，避免模型臆造参数或静默丢失用户要求。
	\item 构建可信文献检索闭环，串联 \textbf{OpenAlex 检索、Crossref 交叉核验、Reviewer LLM 相关性判定、去重与引用配额控制}；将核验文献组织为 Evidence Bundle 提供给 Writer，降低无关文献与不可验证引用进入写作结果的风险。
	\item 建设有界运行框架（\textbf{Agent Harness}），由确定性 Python 流程编排生成、校验与文件写入；通过 \textbf{Diff Gate} 检查引用、数字、公式及文档结构，配合文档副本隔离与快照回滚保护源文件，并引入调用预算、超时重试及 \textbf{Langfuse} 全链路追踪。
\end{itemize}
